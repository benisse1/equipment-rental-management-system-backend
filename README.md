Steps to Run the API
----------------------------------------

1. Ensure PostgreSQL is running and create a database named "erms_db".
2. Open "src/main/resources/application.properties" and confirm your PostgreSQL username and password are correct.
3. Open a terminal in the root directory of this project.
4. Run the command: ".\mvnw spring-boot:run"
5. The application will start on port 8081.
6. Use Postman to test the endpoints using the provided Postman collection file ("equipment-rental-management-system-midterm.postman_collection.json").
